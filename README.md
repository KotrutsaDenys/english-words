# English Words

Особистий тренажер англійських слів: картки з інтервальним повторенням, британська та ірландська вимова, свої слова, щоденний звіт.

- Сайт: статичні файли в `public/`, деплой через Cloudflare Workers Builds (кожен push у `main`).
- Стартовий набір слів: `public/words.js`. Нові слова додаються в кінець своєї теми з унікальним `id`.
- Прогрес зберігається в браузері телефона (localStorage). Резервна копія: Налаштування → Зберегти копію.
- Після змін у файлах піднімай `CACHE` у `public/sw.js` лише якщо треба примусово скинути офлайн-кеш.
