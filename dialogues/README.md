# Діалоги

Кожен діалог — файл `dialogues/<id>.json`, порядок у списку — `dialogues/_order.json`.
Після зміни: `python3 tools/build_dialogues.py` (перевіряє формат і русизми, збирає `public/dialogues.js`),
потім `python3 tools/stamp.py`. Озвучку робить GitHub Actions (`.github/workflows/dialogue-audio.yml`,
`tools/dialogue_audio.py`) після пушу в `main`, а потім сам комітить `public/audio/dlg/` і `public/dialogue-audio.js`.

Додаються порціями по 3 діалоги, коли Денис пише «діалоги».

## Формат

```json
{
  "id": "airport-checkin",            // латиницею, як ім'я файла; не змінювати (прогрес у ew.dialogs)
  "title": "Checking in at the airport",
  "uk": "Реєстрація й здача багажу",
  "icon": "plane",                    // plane, cup, house, … (ICON у app.js, DLG_ICONS)
  "level": "A2",
  "minutes": 6,
  "place": "Аеропорт Дубліна, стійка здачі багажу",
  "scene": "Де ти, хто з тобою говорить і про що (2–3 речення)",
  "goal": "Що треба зробити в розмові",
  "roles": {
    "a": { "en": "Check-in agent", "uk": "Працівниця на стійці", "voice": "f1" },
    "b": { "en": "You", "uk": "Ти, пасажир", "voice": "m1", "you": true }
  },
  "phrases": [ { "en": "...", "uk": "...", "note": "необов'язково" } ],      // 6–10 ключових фраз
  "lines": [
    { "s": "a", "en": "...", "uk": "...",
      "say": "як читати вголос (цифри словами), необов'язково",
      "alt": [ { "en": "...", "uk": "...", "say": "..." } ],               // «Інакше можуть сказати» / «Можна сказати й так»
      "note": "пояснення українською, необов'язково" }
  ],
  "tips": [ "Корисно знати: 2–4 пункти" ]
}
```

- Репліки: 14–24, у кожної ролі щонайменше 6. Роль з `"you": true` — це Денис, її грає він у рольовій грі.
- Переклади реплік різні (з них беруться варіанти в тесті «Послухай і вибери переклад»).
- Пояснення, де прямого відповідника немає, починаються з «Прямого відповідника немає: ».
- Голоси: `m1` — VCTK p245 (Дублін, чоловік, завжди «ти»), `m2` — p298 (Тіпперері, чоловік), `f1` — p288 (Дублін, жінка).
  Модель Chatterbox Turbo (Resemble AI, MIT) копіює тембр і акцент з одного речення VCTK (CC BY 4.0).

## Озвучка

Один файл на діалог `public/audio/dlg/<id>-<хеш>.mp3`: спершу всі репліки поспіль із природними паузами
(так грає «Слухати весь діалог»), потім усі `alt` по черзі реплік, потім ключові фрази.
`window.DLG_AUDIO[id] = [хеш, [початок, кінець], …]` у тому самому порядку (`C.dialogClips` у core.js).
Хеш рахується лише від тексту, що звучить, і голосів: зміна перекладу чи пояснення озвучку не чіпає.
